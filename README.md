# Introduction
This game is part of CPE494 course at KMUTT. This course is about using C++ language and Opengl library to make a 3D game that we desired.

## Idea
we want to do isometric view bow shooting game where objective is to destroy all crystal that keep spawning moster and corrupt the land.

# Build
1. create build folder
2. open cmake program
3. select this repository as source and the build folder as target
4. click on configure and then generate button
5. then you shall find the sln file in the build folder
